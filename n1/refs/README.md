# refs/ — 本地版权材料存档（仅本地，永不推送）

存放网络校对过程中下载/保存的**版权材料**，例如：

- JLPT N1 历年真题 PDF / 图片扫描版
- 答案速查表 / answer key
- 备考机构整理的原题截图

## 约定

- 本目录已被 `.gitignore` 排除（`refs/*`），**内容永不进入 Git / GitHub**。
- 每个文件建议按 `年份月份_科目_来源.ext` 命名，如 `2024-12_vocab_jlegrammar.pdf`。
- 对应的**非版权元数据**（URL、覆盖范围、校对结论）统一记录在
  `guides/source-log.md`，那部分可以入库。
- 密码、密钥等敏感信息不得放入本目录（密码在 `docs/.secret.txt`）。

## 归档时对照 `guides/source-log.md` 记录

|------|------|
